# Jev Decisions 0.1.0

The first tagged release of **Jev Decisions Plugin for Hermes (and other AI Agents)** adds focused reviews for plans, proposed actions, answers, and the evidence behind completion claims.

Jev supplies a second assessment without replacing the agent's main model. Hermes retains tool execution, permissions, and human approval.

## Included in this release

- **Typed Jev reviews through OpenRouter.** Ask custom questions with Noul, Choice, and Score responses, or use 25 prepared workflows for plans, commands, evidence, output quality, memory, choices, and follow-up decisions.
- **Six Hermes tools:** `jev_decide`, `jev_workflow`, `jev_gateway`, `jev_ingest`, `jev_ledger`, and `jev_loop`.
- **Optional automatic reviews.** Three lifecycle observer hooks cover proposed tool calls, returned results, and answers. Networked automatic reviews are off by default and require explicit opt-in.
- **Local evidence checks.** Completion checks require explicit change, readback, and evidence flags. Observation comparisons require an expected value; an available service or device is not proof that a task succeeded.
- **Decision history.** Record decisions, observations, outcomes, and human labels. Reopen decisions when evidence changes. Unknown outcomes remain unknown instead of being counted as failures.
- **Cases and reporting.** Supporting Python commands provide case lists, commitment candidates, snapshots, and review summaries.
- **Python and CLI access.** Supporting interfaces can be used outside Hermes. They do not automatically integrate approval enforcement into other agent frameworks.

## Reliability work included

- Packaged the public runtime dependencies needed by a clean installation.
- Prevented missing or non-boolean verification fields from being accepted as success.
- Required explicit expected-state comparisons for observation verification.
- Added invocation-ID correlation for simultaneous calls to the same tool.
- Added locked, flushed journal appends and regression coverage.
- Kept automatic journal records to metadata rather than raw tool arguments and results.

## Requirements and important boundaries

**An OpenRouter API key is required to run Jev model reviews.** The included journals and deterministic checks are supporting utilities; they do not run Jev and are not a replacement for the model.

Reviews in 0.1.0 are advisory. They do not authorize commands, block execution, or replace human approval. A successful tool handler does not prove an external task succeeded. The agent still needs evidence from the correct target.

This release does not replace or modify LCM, select a context engine, or add context compaction. Native Jev smart approval integration is not included in 0.1.0.

Linux is exercised by CI. Journal locking uses POSIX facilities, so native Windows is not supported by that implementation; use Linux or WSL. Redaction is best effort. Manual journal entries persist supplied content, and journals are not cryptographically tamper-evident.
