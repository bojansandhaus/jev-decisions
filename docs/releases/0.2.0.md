# Jev Decisions 0.2.0

Jev Decisions now offers an optional command approval reviewer alongside its existing planning, evidence, and output reviews. It uses Jev through OpenRouter without replacing your main model or changing LCM.

## New in 0.2.0

- An advisory `approval_review` workflow for reviewing supplied commands. Its recommendations do not authorize execution.
- An optional `jev-decisions-approval` companion provider for Hermes's native smart approval route. Native activation is a separate setup step; installation does not enable it.
- Typed questions covering operator policy, recovery impact, credential access, outbound transfers, and attempts to manipulate the reviewer.
- Conservative response validation and escalation for incomplete, invalid, unavailable, or expired reviews.
- OpenRouter-only provider routing, including rejection of lookalike endpoint hosts.
- Approval setup documentation and regression tests.

## Requirements and boundaries

**An OpenRouter API key is required for Jev model reviews and the approval provider.** Local journals and deterministic checks are supporting utilities, not a replacement for Jev.

Hermes retains execution authority and enforcement. The native provider reviews only commands that Hermes sends to its approval gate; it is not a sandbox or a universal tool firewall. An approval recommendation is not proof that a command will achieve its intended result.

The existing six tools remain available. This release does not replace LCM, register a context engine, alter compression, or change ordinary model selection. Automatic review hooks and native approval selection remain separate opt-in settings.

## Updating

Update the base plugin and install matching package dependencies before setting up the companion. Follow `docs/approvals.md` for the supported provider configuration. Start a fresh Hermes process to load updated modules. Keep your existing approval configuration if you do not want native Jev approvals.
