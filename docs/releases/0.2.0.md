# Jev Decisions 0.2.0

This release adds an opt in `approval_review` workflow and an approval only companion provider adapted from [anpicasso/hermes-jev-approvals](https://github.com/anpicasso/hermes-jev-approvals).

The provider uses OpenRouter's typed Jev Decisions endpoint and requires `OPENROUTER_API_KEY`. Invalid, incomplete, unavailable, or expired reviews escalate rather than approve. Installation does not enable smart approvals or change Hermes approval policy.

The existing six tools, journals, deterministic gateway, LCM integration boundary, context handling, and ordinary model routing remain unchanged. Native provider activation is a separate setup step and is not performed by this release.
