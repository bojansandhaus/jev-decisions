# Jev Decisions 0.2.1

This release adds provider selection for Jev model reviews.

Set `JEV_PROVIDER_MODE` to one of:

* `typesafe`, direct TypeSafe only
* `openrouter`, OpenRouter only
* `typesafe_then_openrouter`, TypeSafe primary with OpenRouter fallback
* `openrouter_then_typesafe`, OpenRouter primary with TypeSafe fallback

The default remains `openrouter`, preserving existing installations. Credentials are read from `TYPESAFE_API_KEY` and `OPENROUTER_API_KEY` through the active Hermes secret scope. Fallbacks are attempted only after the selected primary request fails, and malformed responses remain failures.
