Jev Decisions 0.2.1 adds selectable TypeSafe and OpenRouter routing for model reviews.

Modes:
- `typesafe`: TypeSafe only
- `openrouter`: OpenRouter only
- `typesafe_then_openrouter`: TypeSafe primary, OpenRouter fallback
- `openrouter_then_typesafe`: OpenRouter primary, TypeSafe fallback

Configure `JEV_PROVIDER_MODE`. Credentials are read as `TYPESAFE_API_KEY` and `OPENROUTER_API_KEY` through the active Hermes secret scope. The default remains `openrouter` for backward compatibility.

Verified with the full test suite, Python 3.10, 3.11, and 3.12 CI, plugin doctor, live TypeSafe and OpenRouter requests, live fallback checks in both directions, and the public secret scan.
