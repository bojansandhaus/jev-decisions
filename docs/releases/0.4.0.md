# Jev Decisions 0.4.0

This release adds learned corrections: a store of written rules that carry a track record, gain severity when a mistake keeps happening anyway, and retire when they prove to be noise.

## What a lesson is

A lesson is two things together: the rule, written as the right way to do it, and a precise description of the mistake as it is about to happen. The second half is what makes it work. A rule described by topic gives a matcher nothing to catch. A rule that names the action gives it something specific.

Set one from a single call:

```
jev_lessons action=add text="Save output with Out-File -Encoding utf8" detect="a bare > redirect writing output as UTF-16"
```

Mark it as an owner rule with `source=owner` and it starts as a hard stop instead of advice, and can never retire.

## Severity escalates on its own

A new lesson starts as a `nudge`. A second correction that repeats an existing lesson sharpens that lesson rather than adding a near copy, and that repeat is counted as an escape. Once a lesson has escaped twice it becomes a `kick`, which stops the action instead of advising about it.

This is the part worth having: the store decides when advice has earned the right to be a stop, from evidence rather than from whoever wrote it.

## Noise retires

A lesson that is judged relevant many times without ever catching anything is noise, and it retires. The tally is:

- `surfaced`: times the lesson was judged relevant to an action.
- `catches`: mistakes caught before they happened.
- `escapes`: times the mistake happened anyway.

A lesson also loses ranking weight as it surfaces without catching anything, so a noisy lesson fades before it is retired rather than being trusted the whole way.

## Where a lesson can stop something

The local check is deterministic and provider free. It compares the wording of the action with the wording of the lesson's rule and its detect line. That means it is precise on a close match and it misses a paraphrase. A `kick` lesson therefore stops an action when the two read nearly the same, and does nothing when they do not.

That limitation is a test, not a footnote: `test_a_paraphrase_does_not_clear_the_kick_floor` asserts the miss so the boundary cannot drift silently. The deterministic check is a prefilter and a fast local stop. The semantic judgement still belongs to Jev through an explicit review.

Enforcement remains opt in and global, exactly as in 0.3.0. In the default `shadow` mode a kick lesson stops nothing. The match is written to the ledger as `lesson_would_kick` so you can see what enforcement would have done before you turn it on, and no catch is counted because nothing was caught.

## Packs carry proven lessons between installs

`jev_lessons action=export` writes the lessons that actually caught something, with their severity and track record. `action=import` loads a pack, and an imported lesson arrives with no local track record: it has to earn its own.

> -- psygns, osENV.io `README.md`

> "Lessons that Jev keeps calling relevant but that never catch anything are noise: they retire."
> -- psygns, osENV.io `learn.go`

**No code was copied from that project.** The repository has no license file, so its source is all rights reserved, and only the design was studied. This release is an independent Python implementation. Two things differ on purpose:

- Upstream ranks lessons with vector similarity. This implementation uses a deterministic lexical score, because the plugin stays dependency free and its ranking has to be auditable line by line.
- Upstream escalates a lesson on a repeat when Jev judges the new correction the same as the old one. This implementation merges on a deterministic wording match, with `action=edit` available to correct a wrong merge.
